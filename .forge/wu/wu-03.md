# Add fog mask data model and persistence

## Outcome
Fog mask is represented as a `Uint8Array` (one byte per pixel — 0=revealed, 255=fogged). Pure functions apply reveal and re-fog brush strokes to the mask. Masks serialize to PNG for storage and deserialize back. Per-image fog state round-trips through SQLite without data loss. `bun test` exits 0.

## Values
1. Correctness — pixel-level accuracy of reveal/re-fog operations.
2. Testability — all fog logic is pure functions, no canvas dependency.
3. Performance — operations on a 4000x3000 mask complete in <50ms.

## Context
- `src/db/images.ts` — `updateFogMask(db, imageId, mask: Buffer | null)` stores fog mask as BLOB in SQLite. Already created in wu-01.
- `src/db/database.ts` — `initDatabase()` provides the database connection.
- `src/types.ts` — shared types. Add `FogMask` type here.
- The fog mask is a 2D grid stored as a flat `Uint8Array` of length `width * height`. Each byte represents one pixel's fog state: 255 = fully fogged (opaque black), 0 = fully revealed (transparent).
- On the client side, this mask will be rendered onto a canvas using `ImageData` (RGBA). The server-side model only tracks the alpha channel.

## Requirements

### 1. FogMask type
```typescript
interface FogMask {
  width: number;
  height: number;
  data: Uint8Array; // length = width * height, values 0-255
}

interface FogStroke {
  x: number;        // center x in image coordinates
  y: number;        // center y in image coordinates
  radius: number;   // brush radius in pixels
  mode: 'reveal' | 'fog';
}
```

Add these to `src/types.ts`.

### 2. Mask creation
`createMask(width: number, height: number): FogMask` — returns a fully fogged mask (all bytes = 255).

`createRevealedMask(width: number, height: number): FogMask` — returns a fully revealed mask (all bytes = 0). Useful for tests.

### 3. Stroke application
`applyStroke(mask: FogMask, stroke: FogStroke): void` — mutates the mask in place.

- For mode `'reveal'`: set pixels within the circle to 0.
- For mode `'fog'`: set pixels within the circle to 255.
- Circle defined by `(stroke.x, stroke.y)` center and `stroke.radius`.
- Only iterate over the bounding box of the circle, clamped to mask dimensions.
- Pixel `(px, py)` is inside circle if `(px - x)² + (py - y)² <= radius²`.
- Coordinates are in image pixel space (0,0 = top-left).

`applyStrokes(mask: FogMask, strokes: FogStroke[]): void` — applies multiple strokes in order.

### 4. Mask query
`isRevealed(mask: FogMask, x: number, y: number): boolean` — returns true if pixel at (x,y) is revealed (value = 0). Returns false for out-of-bounds.

`getRevealedPercentage(mask: FogMask): number` — returns 0.0 to 1.0, fraction of pixels that are revealed. Useful for debugging/UI.

### 5. PNG serialization
The fog mask must be stored as a compact binary format in SQLite. Use PNG encoding with a single-channel (grayscale) image.

`serializeMask(mask: FogMask): Promise<Buffer>` — converts the `Uint8Array` mask to a grayscale PNG buffer. Use the simplest possible PNG encoder — construct the raw PNG binary manually:
- PNG signature (8 bytes)
- IHDR chunk: width, height, bit depth 8, color type 0 (grayscale)
- IDAT chunk: zlib-compressed filtered scanlines (filter byte 0 = None for each row, then the row's pixel data)
- IEND chunk
- Use Bun's built-in `Bun.deflateSync()` for zlib compression of the IDAT data.
- CRC32 for each chunk — implement a simple CRC32 function or use `Bun.CryptoHasher` if suitable.

`deserializeMask(png: Buffer): FogMask` — parses a grayscale PNG back to a `FogMask`. Read IHDR for dimensions, decompress IDAT with `Bun.inflateSync()`, strip filter bytes from scanlines, return the pixel data as `Uint8Array`.

If implementing a raw PNG encoder is too complex, an acceptable alternative: store the mask as raw zlib-compressed bytes with a small header (4 bytes width + 4 bytes height + compressed data). This is simpler and still compact. Choose whichever approach is more straightforward.

### 6. Persistence integration
`saveFogMask(db: Database, imageId: string, mask: FogMask): Promise<void>` — serializes mask and calls `updateFogMask(db, imageId, buffer)`.

`loadFogMask(db: Database, imageId: string): Promise<FogMask | null>` — loads the blob from DB, deserializes. Returns null if no mask stored (image is fully fogged — create a new mask on demand).

### 7. Tests

**test/fog/mask.test.ts:**
- `createMask` returns mask with all bytes = 255.
- `applyStroke` with mode 'reveal' sets center pixel to 0.
- `applyStroke` with mode 'fog' on revealed mask sets pixels back to 255.
- Stroke at edge of mask doesn't go out of bounds (no crash, partial circle).
- Stroke at negative coordinates doesn't crash.
- Stroke with radius 0 affects only the center pixel.
- Large stroke reveals correct circular area (check a few sample points inside and outside).
- `isRevealed` returns correct values.
- `getRevealedPercentage` returns 0.0 for fully fogged, 1.0 for fully revealed.
- Reveal then re-fog same area: mask is fully fogged again.

**test/fog/serialize.test.ts:**
- Serialize then deserialize a small mask (10x10): data matches exactly.
- Serialize then deserialize a mask with mixed revealed/fogged pixels: data matches.
- Round-trip preserves width and height.
- Deserialize of corrupted data throws (or returns null).
- Persistence: save to in-memory DB, load back, mask data matches.

## Constraints
- `bun test` must pass.
- No npm dependencies. PNG encoding/decoding uses only Bun built-ins (`Bun.deflateSync`, `Bun.inflateSync`) and manual binary construction.
- Fog logic functions must be pure (no side effects except mutating the passed mask).
- Do not modify files outside the Modifies and Creates lists unless strictly required.

## Failure Modes
- **Off-by-one in circle bounds:** Brush reveals wrong pixels. Detection: test stroke at known coordinates and verify exact pixel states.
- **Serialization data loss:** Mask pixels change after round-trip. Detection: byte-level comparison in tests.
- **Large mask performance:** 4000x3000 = 12M pixels. `applyStroke` iterates only the bounding box, not the full mask. Detection: test with large mask completes in reasonable time.
- **CRC32 error in PNG:** Wrong CRC makes the PNG unreadable. Detection: serialize → deserialize round-trip test.
