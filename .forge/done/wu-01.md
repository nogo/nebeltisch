# Initialize project and server skeleton

## Outcome
`bun run dev` starts an HTTP server on port 3000 that serves a static HTML page at `/` and responds to `GET /api/health` with `{"status":"ok"}`. SQLite database is created on first run with the full schema. All data-layer CRUD functions exist and pass tests. `bun test` exits 0.

## Values
1. Correctness — schema and data layer must be solid, everything else builds on this.
2. Simplicity — no frameworks, no abstractions beyond what's needed.
3. Testability — every data function is a pure function that takes a `Database` instance.

## Context
- This is a greenfield project. No existing code.
- Runtime: Bun (latest stable). No npm frameworks.
- Database: `bun:sqlite` with WAL mode.
- The server uses `Bun.serve()` directly — no Hono, no Express, no Elysia.

## Creates
- `package.json` — name: "fogofwar", scripts: `dev`, `start`, `test`.
- `tsconfig.json` — strict mode, target ESNext, module ESNext, moduleResolution Bundler.
- `src/index.ts` — entry point, `Bun.serve()` with fetch handler and websocket stub.
- `src/db/schema.ts` — SQLite schema creation function.
- `src/db/database.ts` — database initialization (open, WAL mode, create tables).
- `src/db/adventures.ts` — adventure CRUD functions.
- `src/db/images.ts` — image record CRUD functions.
- `src/db/tokens.ts` — token CRUD functions.
- `src/routes.ts` — HTTP route dispatcher (switch on pathname).
- `src/types.ts` — shared TypeScript types/interfaces.
- `public/index.html` — minimal HTML placeholder page.
- `test/db/adventures.test.ts` — adventure CRUD tests.
- `test/db/images.test.ts` — image record CRUD tests.
- `test/db/tokens.test.ts` — token CRUD tests.
- `test/db/schema.test.ts` — schema creation tests.

## Modifies
None.

## Requirements

### 1. Package and TypeScript config
`package.json` with:
- `"name": "fogofwar"`
- `"scripts": { "dev": "bun run --hot src/index.ts", "start": "bun run src/index.ts", "test": "bun test" }`
- No dependencies.

`tsconfig.json` with strict mode, ESNext target/module, Bundler moduleResolution, `src` in include.

### 2. SQLite schema
Tables created via a `createSchema(db: Database)` function:

**adventures**
- `id` TEXT PRIMARY KEY (nanoid or crypto.randomUUID)
- `name` TEXT NOT NULL
- `gm_password` TEXT NOT NULL
- `player_link` TEXT NOT NULL UNIQUE
- `active_image_id` TEXT NULL (FK to images.id)
- `created_at` TEXT NOT NULL DEFAULT (datetime('now'))

**images**
- `id` TEXT PRIMARY KEY
- `adventure_id` TEXT NOT NULL (FK to adventures.id, ON DELETE CASCADE)
- `filename` TEXT NOT NULL
- `original_name` TEXT NOT NULL
- `width` INTEGER NOT NULL
- `height` INTEGER NOT NULL
- `fog_mask` BLOB NULL (PNG of the fog mask, NULL = fully fogged)
- `sort_order` INTEGER NOT NULL DEFAULT 0
- `created_at` TEXT NOT NULL DEFAULT (datetime('now'))

**tokens**
- `id` TEXT PRIMARY KEY
- `adventure_id` TEXT NOT NULL (FK to adventures.id, ON DELETE CASCADE)
- `name` TEXT NOT NULL
- `color` TEXT NOT NULL
- `x` REAL NOT NULL DEFAULT 0
- `y` REAL NOT NULL DEFAULT 0
- `player_session_id` TEXT NULL (links to the WS connection that owns this token)
- `created_at` TEXT NOT NULL DEFAULT (datetime('now'))

Enable foreign keys: `PRAGMA foreign_keys = ON`.
Enable WAL: `PRAGMA journal_mode = WAL`.

### 3. Database initialization
`initDatabase(path?: string): Database` — opens (or creates) the SQLite file at the given path (default: `./data/fogofwar.db`). Creates `data/` directory if missing. Calls `createSchema`. Returns the `Database` instance.

For tests, pass `":memory:"` to get an in-memory database.

### 4. Adventure CRUD
All functions take `db: Database` as first argument.

- `createAdventure(db, { name, gmPassword }): Adventure` — generates ID, player_link (short random code), inserts row, returns full record.
- `getAdventure(db, id): Adventure | null`
- `getAdventureByPlayerLink(db, playerLink): Adventure | null`
- `setActiveImage(db, adventureId, imageId): void` — updates `active_image_id`. Throws if image doesn't belong to adventure.
- `deleteAdventure(db, id): void`

### 5. Image record CRUD
- `createImageRecord(db, { adventureId, filename, originalName, width, height }): ImageRecord` — generates ID, inserts row.
- `getImagesByAdventure(db, adventureId): ImageRecord[]` — ordered by sort_order.
- `getImage(db, id): ImageRecord | null`
- `updateFogMask(db, imageId, mask: Buffer | null): void`
- `deleteImage(db, id): void`

### 6. Token CRUD
- `createToken(db, { adventureId, name, color }): Token`
- `getTokensByAdventure(db, adventureId): Token[]`
- `updateTokenPosition(db, tokenId, x: number, y: number): void`
- `deleteToken(db, id): void`

### 7. HTTP server
`Bun.serve()` on port `process.env.PORT || 3000`.

Route dispatcher in `src/routes.ts`:
- `GET /` → serve `public/index.html`
- `GET /api/health` → `{"status":"ok"}`
- Anything under `/public/*` → serve static file from `public/` directory
- Everything else → 404

WebSocket handler: stub with `open`, `message`, `close` that just log. Will be implemented in wu-04.

### 8. Tests
Use `bun:test` (`describe`, `test`, `expect`). Each test file creates an in-memory database.

**schema.test.ts:**
- Schema creates all tables without error.
- Running schema twice is idempotent (use IF NOT EXISTS).

**adventures.test.ts:**
- Create adventure returns record with all fields.
- Get adventure by ID returns correct record.
- Get adventure by player link works.
- Set active image updates the record.
- Set active image throws for image not in adventure.
- Delete adventure cascades to images and tokens.

**images.test.ts:**
- Create image record returns record with all fields.
- List images by adventure returns correct records ordered by sort_order.
- Update fog mask stores and retrieves binary data.
- Delete image removes record.

**tokens.test.ts:**
- Create token returns record with all fields.
- List tokens by adventure returns correct records.
- Update token position changes x, y.
- Delete token removes record.
- Deleting adventure cascades to tokens.

## Constraints
- `bun test` must pass.
- No npm dependencies. Use only Bun built-ins and standard Web APIs.
- Do not modify files outside the Creates list.
- Database file stored in `./data/` directory (gitignored).
- All IDs generated with `crypto.randomUUID()`.

## Failure Modes
- **Schema migration breaks on re-run:** Tables must use `CREATE TABLE IF NOT EXISTS`. Detection: run schema twice in tests.
- **Foreign keys not enforced:** SQLite has FK enforcement off by default. Detection: test that deleting an adventure cascades to images.
- **WAL mode not enabled:** Concurrent reads would block. Detection: assert `PRAGMA journal_mode` returns `wal` in schema test.
